# Flechas de orden

`sort_down.svg.tmpl` y `sort_up.svg.tmpl` son adaptaciones de las flechas de
orden de **BreezeStyleSheets**, con el marcador `@COLOR@` sustituido en tiempo
de ejecución por el color de acento del tema activo.

- Proyecto: https://github.com/Alexhuszagh/BreezeStyleSheets
- Commit de referencia: `37199e3bd52ba6aa31bd82e33c6202c0c0f0b180`
- Autoría: Colin Duquesnoy y Alex Huszagh
- Licencia: MIT (ver `LICENSES/breeze-stylesheets-LICENSE.md`)

El resto del estilo de tabla (`app/theme/base.qss`) sigue la *estructura* de
Breeze (sin borde exterior, separadores sin duplicar, estados de hover y de
columna ordenada) con la paleta Dracula del proyecto.
